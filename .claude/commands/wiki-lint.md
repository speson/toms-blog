# /wiki-lint

위키 상태를 점검하고 개선점을 제안합니다.

## 실행 단계

1. `content/wiki/index.md` 읽어서 전체 위키 구조 파악
2. 모든 위키 페이지 스캔하며 다음 항목 점검:

### 점검 항목

| 항목          | 설명                                                        |
| ------------- | ----------------------------------------------------------- |
| 고아 페이지   | index.md에 없는 위키 페이지                                 |
| 깨진 참조     | 존재하지 않는 페이지로의 링크                               |
| 오래된 정보   | `last_covered`가 30일 이상 지난 엔티티                      |
| 누락 엔티티   | 포스트에 3회 이상 등장하지만 위키 페이지가 없는 태그/엔티티 |
| 누락 토픽     | 포스트에 5회 이상 등장하지만 위키 토픽이 없는 태그          |
| 포스트 누락   | 최근 발행된 포스트가 관련 위키 페이지에 반영되지 않은 경우  |
| 교차참조 부족 | 관련 엔티티/토픽 간 링크가 빠진 경우                        |

3. 점검 결과를 리포트로 표시:

```
## 위키 린트 결과

### 문제 발견
- [오래된 정보] entities/chatgpt.md — last_covered: 2026-02-15 (60일 전)
- [누락 엔티티] "Cursor" — 4개 포스트에서 언급, 위키 페이지 없음

### 추천 작업
1. entities/chatgpt.md 업데이트 필요
2. entities/cursor.md 신규 생성 추천
3. topics/ai-coding-tools.md에 최근 3개 포스트 반영 필요
```

4. 사용자 승인 시 자동 수정 진행:
   - 오래된 페이지 업데이트 (최신 포스트 반영)
   - 누락 엔티티/토픽 페이지 생성
   - 교차참조 추가
   - index.md 업데이트
   - log.md에 린트 기록 추가

## 완료 후

```
위키 린트 완료:
- 점검: [N]개 페이지
- 수정: [N]개 페이지
- 신규: [N]개 페이지

다음 린트 추천: [날짜]
```
