안녕하세요, Tom입니다.

[지난 글](/posts/2026-04-01-claude-code-v2186-87)에서 v2.1.86~87의 대규모 버그 수정을 다뤘는데, 이번 v2.1.90~92는 다시 **기능 추가 모드**로 돌아왔어요. 특히 v2.1.90이 볼륨이 크고, 91~92가 뒤를 받치는 구조예요.

## v2.1.90 주요 변경

### 🎯 /powerup — 인터랙티브 레슨

이번 릴리스의 하이라이트예요. `/powerup` 명령어를 실행하면 Claude Code의 기능을 **애니메이션 데모와 함께 배울 수 있는 인터랙티브 레슨**이 열려요. 처음 Claude Code를 접하는 팀원에게 온보딩 용도로 추천하기 좋을 것 같아요.

### 🎯 성능 개선 3종 세트

제가 이번에 특히 주목한 부분이에요.

- **MCP 도구 스키마** — 매 턴마다 JSON.stringify하던 캐시 키 조회가 제거됐어요
- **SSE 스트리밍** — 대용량 프레임 처리가 O(n²)에서 **O(n) 선형**으로 개선
- **긴 대화 세션** — 트랜스크립트 쓰기가 이차 시간에서 선형으로 바뀌면서 세션이 길어져도 느려지지 않아요

긴 세션 자주 쓰는 분들이라면 체감이 확실할 거예요.

### ⚠️ 버그 수정

- `--resume`이 deferred tools/MCP 사용자에게 프롬프트 캐시 미스를 일으키던 문제 수정 (v2.1.69 이후 회귀)
- 포맷-온-세이브 훅이 연속 편집 사이에 파일을 덮어써서 Edit/Write가 실패하던 문제 해결
- auto 모드가 "push 하지 마" 같은 **사용자의 명시적 경계를 무시**하던 문제도 잡혔어요 — 이건 꽤 중요한 수정이더라고요
- 사용량 한도 도달 시 옵션 다이얼로그가 무한 반복 열리며 크래시하던 문제 수정

### 💡 기타 개선

- `.husky` 디렉토리가 보호 디렉토리에 추가 (acceptEdits 모드)
- PowerShell 보안 강화 — trailing `&` 백그라운드 잡 우회, 디버거 행 등 4가지 취약점 수정
- `/resume` 프로젝트 뷰가 병렬 로딩으로 개선

## v2.1.91 주요 변경

### 🎯 MCP 500K 결과 지원

가장 눈에 띄는 변경이에요. MCP 도구가 `_meta["anthropic/maxResultSizeChars"]` 어노테이션으로 **최대 500K까지 결과를 잘림 없이 전달**할 수 있게 됐어요. DB 스키마 같은 큰 결과를 다루는 MCP 서버 운영자에게 게임체인저가 될 것 같아요.

### 💡 기타 개선

- `disableSkillShellExecution` 설정으로 스킬 내 셸 실행을 비활성화할 수 있어요
- 플러그인이 `bin/` 하위에 실행 파일을 포함하고 Bash에서 직접 호출 가능
- **Edit 도구가 더 짧은 `old_string` 앵커**를 사용해서 출력 토큰이 줄었어요
- `--resume` 시 트랜스크립트 체인이 끊어지며 대화 기록이 유실되던 문제 수정

## v2.1.92 주요 변경

### 🎯 forceRemoteSettingsRefresh 정책

엔터프라이즈 관리자를 위한 기능이에요. 이 정책을 설정하면 CLI가 **시작 시 원격 설정을 반드시 갱신**하고, 실패하면 아예 실행하지 않아요 (fail-closed). 보안 정책이 엄격한 조직에서 유용할 거예요.

### 💡 개발자 경험 개선

- **Bedrock 셋업 위자드** — 로그인 화면에서 AWS 인증, 리전 설정, 모델 선택까지 가이드해줘요
- `/cost`에 모델별, 캐시 히트 별 비용 세부 내역 추가
- `/release-notes`가 인터랙티브 버전 피커로 변경
- Pro 사용자에게 프롬프트 캐시 만료 후 언캐시드 토큰 수를 알려주는 힌트 추가

### ⚠️ 버그 수정

- tmux 윈도우가 종료/재정렬된 후 서브에이전트 생성이 영구 실패하던 문제 수정
- 풀스크린에서 동일 메시지가 두 위치에 나타나던 스크롤 버그 수정 (iTerm2, Ghostty 등)
- thinking 블록이 공백만 포함할 때 API 400 에러가 발생하던 문제 수정
- `/tag`, `/vim` 명령어가 제거됐어요 (vim 모드는 `/config`에서 토글)

## 총평

세 버전을 묶어 보면 v2.1.90이 **성능 + 안정성**, v2.1.91이 **MCP 확장**, v2.1.92가 **엔터프라이즈 + DX**로 각각 초점이 달라요. 제가 써본 결과, v2.1.90의 SSE/트랜스크립트 성능 개선이 긴 코딩 세션에서 확실히 체감되더라고요. 그리고 `/powerup`은 팀에 Claude Code를 도입할 때 온보딩 자료로 추천해요.

MCP 서버를 직접 만드는 분이라면 v2.1.91의 500K 결과 지원도 꼭 확인해 보세요!
