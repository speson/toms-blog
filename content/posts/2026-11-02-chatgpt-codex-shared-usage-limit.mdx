12월부터 챗GPT(ChatGPT) 대화와 코덱스(Codex)가 <strong>하나의 사용량</strong>을 같이 써요. 저는 이 변화가 요금은 그대로인데 "어디에 아껴 쓸지"를 내가 정해야 하는 일로 바뀐다는 점에서 중요하다고 봐요. 이 글을 읽으면 무엇이 바뀌는지, 누가 먼저 한도에 걸릴지, 12월 전에 무엇을 해 두면 좋을지 알 수 있어요.

## ChatGPT와 Codex 사용량 통합, 정확히 뭐가 바뀌나요?

OpenAI가 10월 31일 고객센터에 올린 [사용량 안내 문서](https://help.openai.com/en/articles/20001625-understanding-chatgpt-and-codex-usage-limits) 내용을 정리하면 이래요 (2026년 11월 2일 기준).

| 항목 | 지금 | 12월부터 |
| --- | --- | --- |
| 적용 요금제 | - | Plus, Pro, Business |
| Codex·Work | 둘이 한 사용량을 같이 씀 | 그대로 |
| 일반 대화 | 따로 계산 | Codex·Work와 같은 사용량에서 빠짐 |
| Instant 대화 | 따로 계산 | 사용량에서 빠지지 않음 |
| 세는 단위 | 기능마다 다름 | 토큰 |

토큰은 AI가 읽고 쓰는 글자 조각이에요. 질문, 첨부 파일, 답변이 전부 토큰으로 세져요. 그래서 메시지 개수보다 <strong>어떤 모델로 얼마나 긴 일을 시키느냐</strong>가 사용량을 정해요.

Work는 챗GPT가 파일을 만들거나 웹에서 일을 대신 해 주는 기능이에요. 이미 Codex와 사용량을 같이 쓰고 있었어요. 12월에는 여기에 평범한 대화까지 들어오는 셈이에요.

남은 양과 초기화 시각은 Settings → Usage에서 한 번에 보게 돼요. 한도에 걸리면 초기화를 기다리거나, 요금제를 올리거나, 크레딧을 사야 해요.

아직 공개되지 않은 것도 많아요. 정확한 시작 날짜, 요금제별 토큰 양, Free·Enterprise·Edu 요금제가 어떻게 되는지는 문서에 없어요.

## 사용량이 합쳐지면 누가 먼저 한도에 걸릴까요?

OpenAI는 "대부분의 사용자는 지금보다 더 자주 초기화를 기다리지 않을 것"이라고 적었어요. 저는 이 말이 평균적으로는 맞을 거라고 봐요. 다만 사용 습관에 따라 체감은 꽤 갈릴 거예요.

| 사용 습관 | 12월 이후 체감 | 이유 |
| --- | --- | --- |
| 대화는 주로 Instant, 코딩은 가끔 | 거의 그대로 | Instant 대화는 사용량에서 빠지지 않아요 |
| Codex만 많이 쓰고 대화는 적게 | 거의 그대로 | 원래 Codex 사용량이 대부분이에요 |
| 생각하는 모델로 긴 대화 + Codex 많이 | 먼저 걸림 | 대화가 코딩에 쓸 사용량을 같이 깎아요 |
| Pro 100·Pro 500 | 여유가 생김 | 10월 29일 Work·Codex 사용량이 2배가 됐어요 |

가장 조심할 사람은 <strong>Plus에서 두 가지를 다 많이 쓰는 사람</strong>이에요. 지금은 대화를 아무리 오래 해도 Codex 한도는 그대로 남아요. 12월부터는 오전에 생각하는 모델로 긴 문서를 다듬으면 오후 코딩에 쓸 양이 줄어요.

모델 차이도 커요. OpenAI가 공개한 [Plus 5시간 추정치](https://help.openai.com/en/articles/20001516-managing-usage-with-gpt-6-astra-in-work-and-codex)를 보면 같은 사용량으로 이만큼 써요.

| 모델 | Plus 5시간 로컬 메시지 (추정) |
| --- | --- |
| GPT-6 Astra | 5~45개 |
| GPT-6.1 Sol | 15~160개 |
| GPT-6 Luna | 350~3,000개 |

이건 지금 Codex·Work 기준 숫자예요. 대화가 합쳐진 뒤에도 비율은 비슷할 거라고 저는 봐요. 무거운 모델 하나를 습관처럼 켜 두면 사용량이 가장 빨리 줄어요.

Pro 쪽은 오히려 좋은 소식이 먼저 왔어요. [Pro 요금제 안내](https://help.openai.com/en/articles/9793128-about-chatgpt-pro-tiers)에 따르면 Pro 100과 Pro 500은 Work·Codex 사용량이 2배가 됐어요. 예고됐던 Pro 200 축소는 취소됐고, 낮은 사용량을 받던 사람도 2배로 올라 높은 쪽과 같아졌어요. Plus 사용량은 바뀌지 않았어요.

## 12월 전에 무엇을 해 두면 좋을까요?

크게 네 가지예요.

1. <strong>일상 질문은 Instant로 바꿔요.</strong> 맞춤법 확인이나 짧은 검색은 Instant로도 충분해요. 이 대화는 공유 사용량에서 빠지지 않아요.
2. <strong>Codex 기본 모델을 확인해요.</strong> 모든 작업에 가장 무거운 모델을 쓰고 있다면 바꿀 때예요. 기본 모델은 `~/.codex/config.toml`의 `model` 키로 정해요. 방법은 [config.toml 가이드](/posts/2026-09-28-codex-config-toml-guide)에 있어요.
3. <strong>Settings → Usage를 한 주만 지켜봐요.</strong> 지금 어느 요일에 Codex 한도에 걸리는지 알아 두면 12월 이후 변화를 바로 알아챌 수 있어요.
4. <strong>크레딧 자동 충전은 상한을 걸어 둬요.</strong> 사용량이 합쳐지면 한도에 걸리는 순간이 예상보다 빨리 올 수 있어요. 크레딧 가격과 자동 충전 설정은 [Codex 크레딧 가이드](/posts/2026-10-05-codex-credits-plus-pro-billing)에 정리해 뒀어요.

요금제를 바꿀지는 12월에 실제로 써 보고 정해도 늦지 않다고 봐요. OpenAI가 토큰 양을 아직 공개하지 않아서 지금 미리 올리면 근거 없이 돈을 더 내는 셈이에요. 한도가 정말 자주 걸리면 그때 크레딧과 Pro 100 중에 고르면 돼요.

Claude Code와 함께 쓰는 사람이라면 비교 기준도 하나 생겨요. Claude 요금제도 대화와 Claude Code가 한 사용량을 같이 써요. 그 구조와 Pro·Max 선택 기준은 [Claude Code 요금제 가격 차이](/posts/2026-10-22-claude-code-pro-max-pricing)에서 볼 수 있어요.

## 자주 묻는 질문

### 12월 며칠부터 바뀌나요?

아직 정해진 날짜가 없어요. OpenAI 문서에는 "12월부터"라고만 나와 있어요. 날짜가 나오면 이 글을 고칠게요.

### Free 요금제도 사용량이 합쳐지나요?

문서에는 Plus, Pro, Business만 나와요. Free, Enterprise, Edu는 언급이 없어서 지금은 알 수 없어요.

### Pro의 GPT-6 Pro 주간 메시지 한도도 공유 사용량에 들어가나요?

지금은 Work·Codex 사용량과 따로예요. 12월 이후에도 따로 남는지는 아직 발표되지 않았어요.

### 한도에 걸리면 지원팀에 초기화를 요청할 수 있나요?

안 돼요. 지원팀은 사용량을 초기화해 주지 않아요. 사용량이 잘못 계산된 것 같을 때만 조사를 요청할 수 있어요.
