안녕하세요, Tom입니다.

[지난 글](/posts/2026-03-30-claude-code-v2183-85)에서 v2.1.83~85를 다루면서 "팀 & 엔터프라이즈" 기능 중심이었다고 했는데, 이번 v2.1.86~87은 완전히 분위기가 달라요. 한마디로 <strong>버그 사냥 + 성능 다이어트</strong> 릴리스예요.

## v2.1.86 주요 변경

### 토큰 절약 & 성능 개선

제가 이번 릴리스에서 가장 주목한 부분이에요.

- <strong>Read 도구가 컴팩트 라인 넘버 포맷</strong>으로 바뀌고, 이미 읽은 파일을 다시 읽을 때 중복을 제거해요. 긴 세션에서 토큰이 눈에 띄게 줄어들 거예요.
- `@`로 파일을 멘션할 때 내용이 더 이상 JSON 이스케이프되지 않아서 <strong>토큰 오버헤드가 감소</strong>했어요.
- Bedrock, Vertex, Foundry 사용자를 위해 도구 설명에서 동적 콘텐츠를 제거해서 <strong>프롬프트 캐시 히트율이 개선</strong>됐어요.
- 긴 세션에서 마크다운/하이라이트 렌더 캐시가 메모리를 계속 먹던 <strong>메모리 누수</strong>도 잡혔어요.

### 개발자 경험 개선

- `X-Claude-Code-Session-Id` 헤더가 API 요청에 추가돼서, 프록시에서 세션별로 요청을 묶어 추적할 수 있게 됐어요.
- Grep과 파일 자동완성에서 `.jj`(Jujutsu), `.sl`(Sapling) 디렉토리가 제외돼요. Jujutsu 쓰는 분들 반가울 거예요.
- 스킬 목록(`/skills`)이 알파벳 순 정렬로 바뀌고, 설명이 250자로 제한돼서 컨텍스트를 아껴요.
- 메모리 저장 알림에서 파일명을 호버하면 하이라이트, 클릭하면 열리는 소소한 UX 개선도 있어요.

### 버그 수정 (대량!)

이번 릴리스의 핵심이라고 할 수 있어요. 무려 <strong>14개 버그 수정</strong>이 포함됐어요.

- `--resume` 옵션이 v2.1.85 이전 세션에서 실패하던 문제 해결
- 프로젝트 루트 밖 파일(예: `~/.claude/CLAUDE.md`)에서 Write/Edit/Read가 실패하던 문제 수정
- Windows에서 스킬 호출마다 불필요한 설정 디스크 쓰기가 발생해 <strong>설정 파일 손상</strong>까지 일어나던 문제 수정
- `/feedback`에서 아주 긴 세션 사용 시 <strong>OOM 크래시</strong> 수정
- `--bare` 모드에서 MCP 도구가 누락되던 문제 수정
- OAuth 로그인 URL 복사 시 ~20자만 복사되던 `c` 단축키 버그 수정
- 좁은 터미널에서 OAuth 토큰이 줄바꿈되며 <strong>토큰 일부가 노출</strong>되던 보안 관련 수정
- v2.1.83 이후 공식 마켓플레이스 플러그인이 macOS/Linux에서 "Permission denied" 발생하던 문제 수정

### VSCode 확장 수정

- 오래 걸리는 작업 중 "Not responding" 표시되던 문제 해결
- Max 플랜 사용자가 OAuth 토큰 갱신(로그인 8시간 후) 시 모델이 Sonnet으로 리셋되던 문제 수정 — 이건 Max 사용자라면 꽤 짜증났을 버그더라고요.

## v2.1.87 주요 변경

v2.1.87은 <strong>핫픽스 릴리스</strong>예요.

- <strong>Cowork Dispatch에서 메시지가 전달되지 않던 버그</strong> 수정

Cowork 기능을 활발히 쓰는 팀이라면 빠르게 업데이트하는 게 좋겠어요.

## 총평

이번 두 버전의 키워드는 <strong>"안정화"</strong>예요. v2.1.83~85에서 조건부 훅, PowerShell 같은 새 기능을 쏟아낸 뒤, 86에서 밀린 버그를 한꺼번에 정리한 느낌이에요. 특히 토큰 절약 관련 개선은 긴 세션을 자주 쓰는 분들에게 체감이 클 거예요.

제가 써본 결과, Read 도구의 중복 제거와 파일 멘션 토큰 최적화가 합쳐지면 긴 코딩 세션에서 꽤 유의미한 차이가 나더라고요. 업데이트 추천해요!
