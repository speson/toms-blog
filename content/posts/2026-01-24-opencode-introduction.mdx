안녕하세요, Tom입니다.

이번에 소개할 <strong>OpenCode</strong>는 제가 최근 한 달간 메인 코딩 도구로 쓰고 있는 AI 에이전트입니다. Claude Code가 유료화되면서 대안을 찾고 있었는데, 이 친구가 꽤 괜찮더라고요.

## OpenCode란? (그리고 제가 선택한 이유)

OpenCode는 터미널 기반 <strong>오픈소스 AI 코딩 에이전트</strong>입니다. Claude Code와 거의 비슷한 기능을 제공하면서도 <strong>완전히 무료</strong>라는 점이 가장 큰 장점입니다.

GitHub 스타가 8만 개 이상인데, 이 정도면 신뢰할 수 있는 프로젝트라고 봅니다. 커뮤니티도 활발하고 업데이트도 자주 나와요.

 <strong>제가 OpenCode를 선택한 이유:</strong>

- Claude Code는 월 $20인데, OpenCode는 공짜
- Claude, GPT, Gemini 중에서 AI 모델을 골라 쓸 수 있음
- LSP 지원이 기본 내장되어 있어서 코드 분석이 정확함

## Claude Code와 비교

| 항목 | OpenCode | Claude Code |
| -------- | ---------------------- | ----------- |
| 가격 | <strong>무료</strong> | 월 $20 |
| AI 모델 | Claude, GPT, Gemini 등 | Claude 전용 |
| 오픈소스 | MIT 라이선스 | 비공개 |
| LSP 지원 | 기본 내장 | 제한적 |

 <strong>Claude Code가 더 나은 점:</strong>

- UI/UX가 더 세련됨
- Anthropic의 공식 지원
- 더 안정적인 동작

<strong>OpenCode가 더 나은 점:</strong>

- <strong>무료</strong> (이게 제일 큼)
- AI 모델 선택의 자유
- 오픈소스라 커스터마이징 가능

## 설치는 정말 쉬워요

한 줄이면 끝입니다:

```bash
curl -fsSL https://opencode.ai/install | bash
```

Homebrew도 지원합니다:

```bash
brew install anomalyco/tap/opencode
```

 <strong>주의:</strong> Node.js 18+가 필요합니다. 설치 전에 확인하세요.

## 뜯어보면 이런 도구예요

### 강점

<strong>1. AI 모델 선택의 자유</strong>

Claude Code는 Claude만 쓸 수 있는데, OpenCode는 Claude, GPT, Gemini 중에서 골라 쓸 수 있습니다. 작업 성격에 따라 모델을 바꿔 쓸 수 있다는 게 구조적인 차별점이에요.

 <strong>참고:</strong> 커뮤니티 후기를 보면 코딩 품질은 Claude Sonnet, 응답 속도는 GPT-4o를 선호하는 평이 많아요.

<strong>2. LSP 지원이 기본 내장</strong>

LSP가 기본 내장이라 TypeScript 타입 에러 같은 정적 분석 정보를 모델이 직접 활용해요. 사용자들이 코드 분석 정확도를 강점으로 꼽는 이유예요.

<strong>3. 확장성</strong>

오픈소스라서 필요하면 직접 수정할 수 있습니다. 프롬프트 템플릿 커스터마이징 같은 것도 코드 레벨에서 가능해요.

### 한계

<strong>1. UI가 좀 투박해요</strong>

Claude Code보다 TUI가 덜 세련됐다는 평이 많습니다. 기능은 다 있는데, 마감 완성도는 상용 도구 쪽이 앞서는 편이에요.

<strong>2. 초기 설정이 필요함</strong>

Claude Code는 바로 쓸 수 있는데, OpenCode는 API 키 설정 같은 초기 설정이 좀 필요합니다. 한 번만 하면 되지만, 귀찮긴 해요.

<strong>3. 공식 지원이 없음</strong>

문제가 생기면 커뮤니티에 의존해야 합니다. Claude Code는 공식 지원이 있어서 더 안심되죠.

## 누구에게 추천하나요?

<strong>추천:</strong>

- Claude Code 비용이 부담스러운 개발자
- 오픈소스 도구를 선호하는 분
- 여러 AI 모델을 테스트해보고 싶은 분

<strong>비추천:</strong>

- GUI를 선호하는 분 (터미널 기반입니다)
- 설정 없이 바로 쓰고 싶은 분
- 공식 지원이 필요한 분

## 총평

OpenCode는 Claude Code의 <strong>무료 대안으로서 충분히 경쟁력</strong> 있습니다. UI는 덜 세련됐지만 기능은 거의 비슷하고, 오히려 AI 모델 선택의 자유도가 더 높아요.

 <strong>비용 절약 팁:</strong> Claude Code 월 $20 vs OpenCode $0. 1년이면 <strong>$240 절약</strong>됩니다. 기능 커버리지는 거의 비슷해요.

물론 Claude Code의 공식 지원과 안정성이 필요하신 분들은 월 $20을 내고 쓰는 것도 충분히 가치 있습니다. 하지만 비용을 절약하고 싶으신 분들은 OpenCode를 강력히 추천드립니다.

여러분도 한 번 써보세요. 생각보다 괜찮을 겁니다.
