AI 코딩 도구가 너무 많아서 어떤 걸 써야 할지 고민이시죠? 저도 그랬어요. Claude Code, Cursor, GitHub Copilot, Devin, OpenCode... 다 좋다고 하는데, 가격도 다르고 기능도 다르고. 직접 하나씩 써보면서 비교하기엔 시간이 너무 들어요.

그래서 제가 정리했습니다. <strong>2026년 7월 기준</strong>, 주요 AI 코딩 도구들의 가격과 기능을 공식 가격 페이지 기준으로 비교하고, 개발자 관점의 선택 기준까지 한 곳에 모았어요.

참고: 이 글은 2월에 처음 쓴 뒤 <strong>7월 15일에 전면 갱신</strong>했어요. 상반기에 바뀐 게 많거든요 — GitHub Copilot이 크레딧 체계로 전환하며 $100짜리 Max 티어를 새로 냈고, Windsurf는 Devin(Cognition)으로 흡수되며 Pro가 $15→$20으로 올랐고, Anthropic은 Claude Pro($20)에 Claude Code를 포함시켰어요. 가격은 2026-07-15에 각 사 공식 페이지에서 확인한 값이고, 언제든 바뀔 수 있으니 결제 전엔 공식 페이지를 다시 확인하세요.

## 한눈에 보는 가격 비교

| 도구 | 무료 플랜 | 유료 가격 | AI 모델 | 형태 |
| ------------------------ | ------------------ | ----------------------------------------- | --------------- | --------------------- |
| <strong>Claude Code</strong> | | Pro $20/월부터 포함, Max $100/월~, API 종량제 | Claude 전용 | 터미널 CLI |
| <strong>Cursor</strong> | (Hobby, 제한적) | Pro $20 / Pro+ $60 / Ultra $200/월 | 멀티 모델 | VSCode 포크 IDE |
| <strong>GitHub Copilot</strong> | (제한적) | Pro $10 / Pro+ $39 / Max $100/월 | 멀티 모델 | IDE 플러그인 |
| <strong>Devin (구 Windsurf)</strong> | (제한적) | Pro $20 / Max $200/월 | 멀티 모델 | 전용 IDE + 클라우드 |
| <strong>OpenCode</strong> | (완전 무료) | 없음 (API 비용만) | 멀티 모델 | 터미널 CLI |
| <strong>Oh My OpenCode</strong> | (완전 무료) | 없음 (API 비용만) | 멀티 모델 | 오케스트레이션 레이어 |

 <strong>핵심 포인트:</strong> "무료"라고 해도 AI API 비용은 별도인 경우가 많아요. OpenCode는 도구 자체는 무료지만, Claude나 GPT API를 쓰려면 해당 API 비용이 들어요. 그리고 올해 상반기의 공통 흐름이 하나 있는데, <strong>"요청 횟수"가 아니라 "달러 단위 크레딧/쿼터"로 청구 방식이 바뀌고 있다</strong>는 거예요. Cursor도, Copilot도, Devin도 전부요.

## 각 도구 상세 비교

### 1. Claude Code (Anthropic)

<strong>가격:</strong> Claude Pro $20/월(연간 결제 시 $17/월)부터 포함, Max $100/월~(Pro의 5x/20x 사용량), 또는 API 종량제
<strong>형태:</strong> 터미널 CLI

저는 이걸 매일 쓰고 있어요. 이 블로그 자체가 Claude Code로 만들어졌습니다.

2월과 비교해 가장 큰 변화는 <strong>진입 가격</strong>이에요. 이제 $20짜리 Pro 플랜에 Claude Code가 포함돼서, 예전처럼 상위 플랜을 고민할 필요 없이 시작할 수 있어요. API로 쓸 경우엔 [Sonnet 5가 프로모션 가격](/posts/2026-07-03-claude-sonnet-5)이라는 점도 커요 — 입력/출력 1M 토큰당 <strong>$2/$10 (2026-08-31까지, 이후 정가 $3/$15)</strong>, Opus 4.8은 $5/$25예요.

<strong>강점:</strong>

- 복잡한 리팩토링에서 압도적인 성능
- 프로젝트 전체 맥락을 이해하는 능력이 뛰어남
- 터미널에서 바로 실행 — IDE 잠김 없음
- 태스크 관리, 백그라운드 서브에이전트, Auto 모드 등 에이전트 기능이 가장 빠르게 확장 중

<strong>약점:</strong>

- Claude 모델만 사용 가능 (다른 모델 선택 불가)
- GUI가 없어서 터미널에 익숙하지 않으면 진입 장벽
- 가격이 사용량에 따라 예측하기 어려울 수 있음

 <strong>참고:</strong> Sonnet 5·Opus 4.7/4.8은 신형 토크나이저를 써서 같은 텍스트도 이전 대비 약 30% 많은 토큰으로 집계된다고 공식 문서에 명시돼 있어요. 단가만 보지 말고 실효 비용으로 비교하세요.

### 2. Cursor

<strong>가격:</strong> Hobby 무료 / Pro $20/월 / Pro+ $60/월 / Ultra $200/월, Teams $40(Standard)·$120(Premium)/유저/월
<strong>형태:</strong> VSCode 포크 IDE

개발자 커뮤니티에서 가장 인기 있는 AI 코딩 도구예요. VSCode를 포크해서 만들었기 때문에 VSCode 확장 프로그램이 대부분 호환됩니다.

한때 유명했던 "fast requests 500회" 개념은 사라졌어요. 지금은 <strong>플랜별로 달러 단위 포함 사용량</strong>이 주어지는 방식이에요 — Pro는 월 $20 상당, Pro+는 $70 상당, Ultra는 $400 상당의 모델 사용량이 포함되고, 소진되면 종량제로 이어져요.

<strong>강점:</strong>

- 자동완성(Tab) 품질이 뛰어남 (유료 플랜은 Tab 무제한)
- Chat + Compose 모드로 유연한 사용
- VSCode 생태계 호환
- 멀티 모델 지원 (Claude, GPT, Gemini 등)

<strong>약점:</strong>

- 포함 사용량이 달러 기준이라, 비싼 모델을 쓰면 빨리 소진됨
- 가끔 무거워지는 느낌
- VSCode에서 Cursor로 옮기면 일부 설정 이슈

 <strong>비용 팁:</strong> Hobby(무료)로 시작해서 써보고, 자동완성이 마음에 들면 Pro로 올리는 걸 추천해요. 포함 사용량이 달러 단위라서, 저렴한 모델을 기본으로 두면 같은 $20으로 훨씬 오래 쓸 수 있어요.

### 3. GitHub Copilot

<strong>가격:</strong> Free (제한적) / Pro $10/월 / Pro+ $39/월 / Max $100/월 / Business $19/석/월 / Enterprise $39/석/월
<strong>형태:</strong> IDE 플러그인 (VSCode, JetBrains, Neovim 등)

가장 범용적이고, 가장 많은 IDE를 지원하는 도구예요. 6월 1일부로 과금 체계가 <strong>GitHub AI Credits</strong> 기반으로 바뀌었어요. 코드 자동완성은 크레딧을 소모하지 않고 유료 플랜에서 무제한이고, 채팅·에이전트 사용이 크레딧을 소모하는 구조예요 (Pro는 월 $15 상당, Pro+는 $70 상당, Max는 $200 상당).

<strong>강점:</strong>

- <strong>$10/월은 여전히 유료 AI 코딩 도구 중 최저가</strong>
- VSCode, JetBrains, Neovim 등 거의 모든 IDE 지원
- GitHub 생태계와의 통합 (Issues, PR, Actions)
- Pro+ 이상은 Claude Opus 4.8, Fable 5 같은 프리미엄 모델도 선택 가능

<strong>약점:</strong>

- 자동완성 품질이 Cursor보다 약간 떨어진다는 평이 많음
- 에이전트 기능은 아직 Claude Code나 Cursor 대비 부족
- 크레딧 체계 전환 직후라 플랜별 실효 사용량 감이 잡히기 전임

 <strong>주의:</strong> Copilot Free는 월 2,000회 자동완성 제한이 있어요 (채팅은 "limited"로만 공시). 활발히 코딩하면 금방 소진돼요. 그리고 새로 생긴 <strong>Max($100/월)</strong>는 에이전트 중심 헤비유저용이라, 자동완성+채팅 위주라면 Pro로 충분해요.

### 4. Devin — 구 Windsurf (Cognition)

<strong>가격:</strong> Free (제한적) / Pro $20/월 / Max $200/월, Teams $80/월 + $40/시트/월
<strong>형태:</strong> 전용 IDE + 클라우드 에이전트

2월에 이 자리에 "Windsurf"라고 썼는데, 이제 그 이름의 제품은 없어요. Cognition(Devin 개발사)이 Windsurf를 인수하면서 브랜드가 통합됐고, windsurf.com 가격 페이지는 devin.ai로 리다이렉트돼요. 3월 개편으로 <strong>Pro가 $15→$20으로 인상</strong>됐고(기존 구독자는 기존 가격 유지), 크레딧 방식이 일일/주간 자동 갱신 쿼터로 바뀌었어요.

<strong>강점:</strong>

- IDE 편집 + 클라우드 에이전트(Devin)를 한 구독으로
- 인라인 편집·Tab 자동완성은 무료 티어에서도 무제한
- $200 Max 티어는 쿼터가 Pro의 약 6배

<strong>약점:</strong>

- 생태계가 Cursor/VSCode 대비 작음
- 쿼터의 정확한 기준(토큰량)이 비공개라 예측이 어려움
- 인수 직후라 제품 방향이 유동적

 <strong>참고:</strong> Teams 가격은 페이지 기준 "$80/월 기본 + $40/시트"인데, 3월 발표문에는 "$40/시트"로만 적혀 있어서 표기가 갈려요. 팀 도입 전에 결제 화면에서 최종 확인하세요.

### 5. OpenCode (오픈소스)

<strong>가격:</strong> 완전 무료 (API 비용만 별도)
<strong>형태:</strong> 터미널 CLI

Claude Code의 오픈소스 대안이에요. <strong>100% 무료</strong>이면서 원하는 AI 모델을 골라 쓸 수 있습니다.

<strong>강점:</strong>

- 도구 자체 비용 $0
- Claude, GPT, Gemini 등 원하는 모델 선택
- LSP 지원 내장 (코드 분석 정확도 높음)
- 활발한 오픈소스 커뮤니티

<strong>약점:</strong>

- Claude Code 대비 에이전트 기능이 부족
- 설정이 좀 복잡할 수 있음
- 기업 지원/SLA 없음

 <strong>API 비용 참고:</strong> OpenCode 자체는 무료지만, Claude API를 쓰면 Anthropic에 비용이 청구돼요. 다만 지금은 Sonnet 5 프로모션($2/$10) 덕분에 종량제가 특히 유리한 시기예요. 제 경우 월 API 비용이 약 $5~15 정도 나와요.

### 6. Oh My OpenCode (오픈소스)

<strong>가격:</strong> 완전 무료 (API 비용만 별도)
<strong>형태:</strong> OpenCode 위의 오케스트레이션 레이어

OpenCode에 멀티 에이전트 오케스트레이션을 더한 도구예요. Categories + Skills 시스템으로 동적 에이전트 조합이 가능합니다.

<strong>강점:</strong>

- 복잡한 작업을 여러 에이전트가 분업
- Prometheus(플래너) + Atlas(오케스트레이터) 시스템
- 비용 효율적 모델 라우팅
- 최근엔 [에이전트 정지 계약(WHEN TO STOP)](/posts/2026-07-14-agents-learn-to-stop) 같은 폭주 방지 장치까지 내장

<strong>약점:</strong>

- 학습 곡선이 가파름
- OpenCode + OMO 모두 설정해야 해서 초기 세팅이 복잡
- 단순 코딩에는 오버킬

 <strong>추천 대상:</strong> AI 에이전트 시스템에 관심 있거나, 복잡한 프로젝트를 AI로 관리하고 싶은 파워 유저

## 예산별 추천

### 무료로 시작하고 싶다면

1. <strong>OpenCode</strong> — Claude Code 스타일 터미널 도구, 완전 무료
2. <strong>GitHub Copilot Free</strong> — IDE 자동완성, 월 2,000회 제한
3. <strong>Cursor Hobby</strong> — VSCode 포크, 제한적 무료 사용

### 월 $10 이하

- <strong>GitHub Copilot Pro ($10/월)</strong> — 가성비 최고. 자동완성 무제한 + 채팅이면 충분한 분들

### 월 $20 안팎

- <strong>Claude Pro ($20/월, Claude Code 포함)</strong> — 터미널 기반, 복잡한 리팩토링이 많은 분. 이 가격대에서 제일 큰 변화예요
- <strong>Cursor Pro ($20/월)</strong> — 자동완성 품질이 중요하고 IDE에서 작업하는 분
- <strong>Devin Pro ($20/월)</strong> — IDE + 클라우드 에이전트를 같이 쓰고 싶은 분

### 상위 티어 ($39~)

- <strong>Copilot Pro+ ($39/월)</strong> — Copilot 생태계에서 Opus 4.8·Fable 5 같은 프리미엄 모델까지
- <strong>Claude Max ($100/월~)</strong> / <strong>Copilot Max ($100/월)</strong> / <strong>Cursor Ultra ($200/월)</strong> / <strong>Devin Max ($200/월)</strong> — 에이전트를 하루 종일 돌리는 헤비유저용

### 비용 무관, 최고 성능

- <strong>Claude Code + Oh My OpenCode</strong> — 멀티 에이전트 오케스트레이션. 비용은 API 종량제로 최적화 가능

## 제 개인 셋업과 월 비용

솔직하게 공개할게요:

| 도구 | 용도 | 월 비용 |
| -------------- | ------------------------------ | -------------- |
| Claude Code | 메인 코딩 도구 | ~$20 (Pro) |
| Oh My OpenCode | 복잡한 프로젝트 오케스트레이션 | $0 (도구 무료) |
| GitHub Copilot | VSCode 자동완성 (보조) | $10 |
| <strong>합계</strong> | | <strong>약 $30/월</strong> |

 <strong>솔직한 생각:</strong> $30/월이 비싸 보일 수 있는데, 생산성 향상을 생각하면 충분히 가치 있어요. Claude Code 없이 이 블로그를 만들었다면 3배는 더 걸렸을 거예요.

<strong>비용 절약 팁:</strong>

- Claude Code를 API 종량제로 쓰면 가벼운 사용 시 $5~10으로 가능 (프로모션 기간엔 더 유리)
- OpenCode로 대체하면 도구 비용 $0 (API만 별도)
- GitHub Copilot Free로 시작해서 부족할 때만 유료 전환

## 총평

2026년 7월 AI 코딩 도구 시장을 정리하면, 가격의 양극단이 더 벌어졌어요. 진입은 더 싸졌고(Claude Pro $20에 Claude Code 포함, Copilot $10), 헤비유저용 티어는 $100~200대로 표준화됐어요(Claude Max, Copilot Max, Cursor Ultra, Devin Max). 그리고 청구 방식은 업계 전체가 "횟수"에서 "달러 크레딧/쿼터"로 이동했어요.

- <strong>처음 시작한다면:</strong> GitHub Copilot Free나 OpenCode로 시작
- <strong>생산성을 높이고 싶다면:</strong> Cursor Pro나 Claude Pro (Claude Code 포함)
- <strong>극한의 효율을 원한다면:</strong> Claude Code + Oh My OpenCode 조합

결국 "<strong>자기 워크플로우에 맞는 도구</strong>"가 최고의 도구예요. 저는 터미널 중심이라 Claude Code가 맞았지만, IDE를 선호하시면 Cursor가 더 좋을 수 있어요.
