9월에 OpenAI가 GPT-6 제품군을 내고, Anthropic도 Claude Opus 5.5를 내면서 AI 모델 가격표가 또 바뀌었어요. 저는 이제 가장 똑똑한 모델을 찾기보다 기본으로 켜 둘 모델을 고르는 게 더 중요한 결정이라고 봐요. 이 글에서는 주요 모델의 API 가격을 공식 가격표로 비교하고, 용도별로 무엇을 고르면 되는지 정리해요.

이 글은 2월에 처음 썼고, 2026년 9월 27일 기준으로 전면 갱신했어요. 7월 판에서는 Claude Sonnet 5의 $2/$10을 8월 31일까지의 프로모션이라고 썼어요. 그런데 Anthropic이 8월 10일 이 가격을 정가로 확정했어요.

## 2026년 9월 AI 모델 API 가격은 얼마인가요?

아래 표는 각 사 공식 가격 페이지에서 확인한 표준 처리 가격이에요. 단위는 100만 토큰당 입력/출력 달러예요 (2026년 9월 27일 확인).

| 모델 | 회사 | API 가격 (입력 / 출력) | 자리 |
| --- | --- | --- | --- |
| GPT-6 Astra | OpenAI | $10 / $50 | 최상위 |
| GPT-6 Sol | OpenAI | $2 / $10 | 복잡한 코딩·에이전트 작업 |
| GPT-6 Luna | OpenAI | $0.10 / $0.50 | 대량 처리 |
| GPT-5.6 Sol | OpenAI | $4 / $20 (프로모션) | 이전 세대 상위 |
| GPT-5.6 Terra | OpenAI | $2 / $12 | 이전 세대 중형 |
| GPT-5.6 Luna | OpenAI | $0.20 / $1.20 | 이전 세대 경량 |
| Claude Fable 5.1 | Anthropic | $10 / $50 | 최상위, 긴 추론 작업 |
| Claude Opus 5.5 | Anthropic | $4 / $20 | 오래 걸리는 에이전트 코딩 |
| Claude Sonnet 5 | Anthropic | $2 / $10 | 기본값 자리 |
| Claude Haiku 4.5 | Anthropic | $1 / $5 | 경량 |
| Gemini 3.1 Pro (Preview) | Google | $2 / $12 | Pro 라인 |
| Gemini 3.8 Flash | Google | $0.75 / $3.75 (12월 31일까지) | 긴 코딩·에이전트 작업 |
| Gemini 3.1 Flash-Lite | Google | $0.25 / $1.50 | 초저가 |

표를 읽을 때 조심할 점이 세 가지 있어요.

- <strong>기한이 있는 가격</strong>: GPT-5.6 Sol 가격은 최소 11월 21일까지 유지되는 프로모션이에요. Gemini 3.8 Flash는 2027년 1월부터 $1.50/$7.50으로 올라요.
- <strong>토크나이저 차이</strong>: Claude 4.7 이후 모델은 새 토크나이저(글을 토큰으로 나누는 규칙)를 써요. 같은 글도 약 30% 더 많은 토큰으로 집계된다고 공식 문서에 적혀 있어요.
- <strong>Opus 세대</strong>: Opus 5와 Opus 4.8은 $5/$25로 남아 있어요. 새로 시작한다면 더 싸고 새로운 Opus 5.5가 먼저예요.

## 코딩에는 어떤 AI 모델이 좋나요?

코딩 기본값 자리에서는 Claude Sonnet 5와 GPT-6 Sol이 같은 $2/$10에 맞붙어요. Anthropic은 Sonnet 5가 일부 설정에서 Opus 4.8 수준에 맞먹는다고 발표했어요. OpenAI는 GPT-6 Sol을 복잡한 코딩과 에이전트 작업용 모델로 소개해요.

오래 걸리는 큰 작업은 한 단계 위를 볼 만해요. Anthropic은 Opus 5.5가 코드베이스 전체 마이그레이션 같은 긴 작업에 특히 강하다고 설명해요. 입력·출력 단가는 Opus 5보다 20% 낮아요.

가장 어려운 문제는 GPT-6 Astra나 Claude Fable 5.1까지 올릴 수 있어요. 다만 둘 다 $10/$50이라 기본값으로 켜 두기에는 비싸요.

저는 기본값 하나와 올려 쓸 모델 하나를 정해 두는 구성이 가장 합리적이라고 봐요. 예를 들어 평소엔 Sonnet 5나 GPT-6 Sol을 쓰고, 막히는 작업만 Opus 5.5나 Astra로 넘기는 식이에요.

참고로 이 블로그는 Claude Code의 도움을 받아 만들고 있어요. 그래서 Claude 쪽에 더 익숙하다는 점은 밝혀 둘게요.

## 대량 처리와 저예산에는 어떤 모델이 싼가요?

작업이 단순하고 양이 많다면 가격 차이가 훨씬 커져요. 용도별로 고르면 이래요.

| 작업 | 추천 모델 | 이유 |
| --- | --- | --- |
| 단순 질의응답·요약 | GPT-6 Luna | $0.10 / $0.50, 이 표에서 가장 쌈 |
| 분류·번역 같은 대량 작업 | Gemini 3.1 Flash-Lite | $0.25 / $1.50 |
| 에이전트 실행 | Gemini 3.8 Flash | 연말까지 $0.75 / $3.75 |
| 경량 에이전트·분류 | Claude Haiku 4.5 | $1 / $5, 배치 처리 시 절반 |

비용을 더 줄이는 방법도 있어요. 결과를 바로 받지 않아도 되면 배치(Batch) 처리를 쓰세요. OpenAI와 Anthropic 모두 표준 가격의 절반이에요.

같은 문서를 반복해서 넣는다면 프롬프트 캐싱(앞부분을 저장해 두고 재사용하는 기능)도 챙기세요. 캐시에서 읽는 입력은 표준 입력보다 훨씬 싸요.

## 이미지·영상과 긴 문서는 어떻게 고르나요?

이미지·영상까지 다루는 멀티모달 작업은 Google 생태계가 가장 넓어요. Gemini Omni Flash는 Gemini API 유료 등급에서 정식 제공되는 영상 생성·편집 모델이에요. 입력은 100만 토큰당 $1.50이에요.

긴 문서는 컨텍스트(한 번에 넣을 수 있는 입력 길이)와 요금 구조를 같이 봐야 해요. Claude 4.6 이후 모델은 100만 토큰 컨텍스트를 추가 요금 없이 써요. 반면 OpenAI GPT-6는 긴 컨텍스트 구간에서 단가가 올라가요. GPT-6 Sol은 이 구간에서 입력이 $4예요.

그래도 컨텍스트가 크다고 다 넣지는 마세요. 긴 입력은 비용이 커지고, 중간 내용을 놓치는 문제(lost in the middle)도 완전히 사라지지 않았어요. 필요한 부분만 발췌해 넣는 쪽이 대부분 더 정확하고 싸요.

결국 고를 건 세 개예요. 기본값 하나, 올려 쓸 모델 하나, 대량 처리용 하나예요. 가격표는 계속 바뀌니 결제 전엔 공식 가격 페이지를 다시 확인하세요.

## 자주 묻는 질문

### GPT-6 API 가격은 얼마인가요?

2026년 9월 기준 100만 토큰당 가격이에요. GPT-6 Astra는 $10/$50, Sol은 $2/$10이에요. Luna는 $0.10/$0.50이에요.

### Claude Sonnet 5 가격이 9월에 올랐나요?

아니요. 원래 9월 1일부터 $3/$15로 오를 예정이었어요. Anthropic이 8월 10일 $2/$10을 정가로 확정하면서 인상은 취소됐어요.

### Claude Opus 5.5와 Opus 5는 무엇이 다른가요?

Opus 5.5의 입력·출력 단가는 $4/$20으로 Opus 5보다 20% 낮아요. Anthropic은 자체 테스트에서 일반 작업 비용이 40% 줄었다고 밝혔어요.

### 가장 싼 AI 모델 API는 무엇인가요?

이 글의 표 기준으로는 GPT-6 Luna가 가장 싸요. 품질이 더 필요하면 Gemini Flash 계열이나 Claude Haiku 4.5를 비교해 보세요.
