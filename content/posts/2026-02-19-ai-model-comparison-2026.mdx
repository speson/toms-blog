ChatGPT, Claude, Gemini 중 무엇을 써야 할지 고민하는 분이 많아요. 저는 세 서비스의 기본 성능 차이보다 내가 매일 쓰는 도구와 얼마나 잘 붙는지가 더 중요한 기준이라고 봐요. 이 글을 읽으면 세 서비스의 구독 가격, 지금 쓸 수 있는 최신 모델, 용도별로 무엇을 고르면 되는지 알 수 있어요.

가격은 2026년 10월 11일 각 회사 공식 페이지에서 확인한 미국 달러 기준이에요. 한국 결제 화면은 세금과 환율 때문에 다를 수 있어요. 이 글은 2월에 처음 썼고, 9월 판의 API 가격 위주 설명을 일반 사용자용 비교로 바꿨어요.

## ChatGPT, Claude, Gemini 구독 가격은 얼마인가요?

세 서비스 모두 무료 요금제가 있고, 월 20달러 안팎에서 맞붙어요.

| 구간 | ChatGPT | Claude | Gemini (Google AI) |
| --- | --- | --- | --- |
| 무료 | Free | Free | 무료 |
| 저가 | Go $8 | 없음 | AI Plus $4.99 |
| 표준 | Plus $20 | Pro $20 (연간 결제 시 월 $17) | AI Pro $19.99 |
| 상위 | Pro $100 / $200 / $500 | Max $100 (5배) / $200 (20배) | AI Ultra $99.99 / $199.99 |

몇 가지 조심할 점이 있어요.

- ChatGPT Go는 광고가 붙을 수 있어요. Go, Plus, Pro는 월 결제만 돼요.
- ChatGPT Pro 세 등급 중 가장 빠른 응답 모드(Ultrafast)는 $500 등급에만 있어요.
- Claude Max와 Google AI Ultra의 "5배·20배"는 바로 아래 요금제 대비 사용량이에요.

저는 대부분의 사람에게 월 20달러 요금제 하나면 충분하다고 봐요. 상위 요금제는 하루 종일 에이전트를 돌리거나 영상을 많이 만드는 경우에만 의미가 있어요.

## 지금 쓸 수 있는 최신 모델은 무엇인가요?

2026년 10월 기준 각 서비스의 주력 모델은 이래요.

| 서비스 | 무료에서 쓰는 모델 | 유료에서 추가되는 모델 |
| --- | --- | --- |
| ChatGPT | GPT-6 Luna | GPT-6.1 Sol, GPT-6 Astra |
| Claude | Sonnet, Haiku | Opus 5.5 (Pro부터), Fable 5.1 (Max는 주간 한도의 50%까지) |
| Gemini | 3.5 Flash-Lite | 3.8 Flash, 3.1 Pro |

모델 이름이 자주 바뀌어서 헷갈리기 쉬워요. 각 회사의 최신 정보는 앱의 모델 선택 메뉴에서 바로 확인하는 게 가장 정확해요.

## ChatGPT, Claude, Gemini는 무엇이 다른가요?

세 서비스 모두 질문 답변, 글쓰기, 파일 분석, 웹 검색은 기본으로 돼요. 차이는 함께 딸려 오는 도구에서 나요.

| 서비스 | 강점이 드러나는 곳 (공식 요금제 페이지 기준) |
| --- | --- |
| ChatGPT | 이미지 생성, 음성 대화, 딥 리서치, Codex, 엑셀·워드·구글 시트 확장 |
| Claude | 코딩 도구 Claude Code, 크롬·마이크로소프트 365 연동, 문서·슬라이드 만들기 |
| Gemini | Gmail·Docs 등 구글 앱 안에서 바로 쓰기, 영상 생성, 5TB 클라우드 저장공간(AI Pro) |

용도별로 정리하면 저는 이렇게 권해요.

- <strong>문서 정리와 이미지, 음성까지 한 앱에서</strong>: ChatGPT Plus
- <strong>코딩과 긴 글 작업</strong>: Claude Pro. Claude Code가 유료 요금제에 포함돼요.
- <strong>Gmail과 구글 드라이브를 매일 쓴다면</strong>: Google AI Pro. 저장공간까지 생각하면 가성비가 좋아요.

참고로 이 블로그는 Claude Code의 도움을 받아 만들고 있어요. 그래서 Claude 쪽에 더 익숙하다는 점은 밝혀 둘게요.

## 개발자라면 API 가격은 어떻게 다른가요?

앱 구독과 API(프로그램에서 모델을 부르는 방식) 요금은 따로예요. 주요 모델의 표준 가격은 이래요. 단위는 100만 토큰당 입력/출력 달러예요 (2026년 10월 11일 확인).

| 모델 | API 가격 (입력 / 출력) |
| --- | --- |
| GPT-6 Astra | $10 / $50 |
| GPT-6.1 Sol | $2 / $10 |
| Claude Fable 5.1 | $10 / $50 |
| Claude Opus 5.5 | $4 / $20 |
| Claude Sonnet 5.5 | $2 / $10 |
| Gemini 3.8 Flash | $0.75 / $3.75 (12월 31일까지) |

Gemini 3.8 Flash는 2027년부터 $1.50 / $7.50으로 올라요. 저는 기본값은 중간 가격대 모델로 두고, 막히는 작업만 상위 모델로 올리는 구성이 합리적이라고 봐요.

## 자주 묻는 질문

### 무료로 쓰기에 가장 좋은 AI는 무엇인가요?

세 서비스 모두 무료 요금제가 있어요. 무료에서도 웹 검색과 파일 업로드가 되니, 자주 쓰는 앱에 맞춰 고르면 돼요.

### ChatGPT Plus와 Claude Pro 중 무엇이 나은가요?

가격은 둘 다 월 20달러예요. 저는 이미지·음성이 중요하면 ChatGPT Plus, 코딩이 중요하면 Claude Pro를 권해요.

### 한국에서도 같은 가격인가요?

공식 가격은 미국 달러 기준이에요. 한국에서는 부가세와 환율이 붙어 결제 금액이 달라질 수 있어요.

### 9월 판의 Claude Sonnet 5는 어떻게 됐나요?

지금 Claude의 최신 Sonnet은 Sonnet 5.5예요. Sonnet 5는 이전 세대 모델로 분류됐고, API 가격은 둘 다 $2 / $10이에요.
