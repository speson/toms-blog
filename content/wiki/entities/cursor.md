# Cursor

## 개요

Anysphere가 만든 VSCode 포크 기반 AI 코딩 IDE. 블로그에서는 오랫동안 Claude Code·Codex·OpenCode의 비교 대상으로 등장했고(가격 비교 가이드, 모델 출시 글의 벤치마크·파트너 인용, 도구 통합 사례), 2026-08-31에 처음으로 단독 주제가 됐다. SpaceX가 2026-06-16 600억 달러 전액 주식으로 인수 계약을 맺고 8월 14일 종결한 뒤, OpenAI가 8월 28일 공급 계약 종료(11월 12일)를 공지한 사건이 계기다. 블로그가 기록한 Cursor의 모델 라인업은 자체 모델 Composer, Claude, Gemini, Grok이며, OpenAI 모델은 트래픽의 약 5%로 11월 12일 종료 예정이다. 가격은 Hobby 무료 / Pro $20 / Pro+ $60 / Ultra $200, Teams $40(Standard)·$120(Premium)으로 기록돼 있다(2026-07-15 갱신 기준).
